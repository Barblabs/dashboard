## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `Barblabs/dashboard` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage roles with neutral names: `implementation` (ready-for-agent) and `hands-on` (ready-for-human). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
