# Feature map

User-facing features of the dashboard. Each file lists what to drive and the end state that proves it. The driver is `../helpers/drive.mjs`.

| Feature | Summary |
|---|---|
| [sign-in-and-roles.md](sign-in-and-roles.md) | Role picker (mock) or Cognito sign-in, persisted session, landing per role, user card, sign out, deactivated |
| [navigation.md](navigation.md) | Login guard and return, per-role sidebar, redirect from `/`, placeholder page, 404 and forbidden |
| [findings.md](findings.md) | Prioritized order in groups, finding detail (Score, vulnerability, asset, threats), Luna action plan, feedback |
| [news.md](news.md) | News Digests by Relevance, earlier digests, labels, the Editor's why, Ransomware.live attribution |
| [connect-cmdb.md](connect-cmdb.md) | Choose iTop, enter credentials, test, connect and first sync |
| [manage-connection.md](manage-connection.md) | Sync now, edit connection dialog, disconnect, sync failure recovery, viewer read-only |
| [tech-stack-inventory.md](tech-stack-inventory.md) | Asset list with filters beside the selected asset's record, keyboard move, pagination |
| [asset-triage.md](asset-triage.md) | Triage banner and queue, declare or clear Exposure and Information Classification |
| [areas.md](areas.md) | Areas imported from the CMDB, owner email per area, status filter |
| [slack.md](slack.md) | Connect Slack, Security Team channel, test message, failed deliveries, disconnect |
| [business-context.md](business-context.md) | Tabbed form, document import draft, domain cleanup, save, viewer read-only |
| [users.md](users.md) | Invite, change role, disable, last-admin protection |
| [super-admin.md](super-admin.md) | Organizations (create, rename, deactivate) and the super admin dashboard |
| [language-switcher.md](language-switcher.md) | ES/EN toggle in the sidebar, persisted |
| [mobile-layout.md](mobile-layout.md) | Phone top bar and drawer navigation, full-width pages, input text that does not zoom, full-screen Finding detail, tab fade, Fab safe areas; desktop unchanged |
